Database

Keeps one library in Postgres, reachable from every device. The connection string stays on this device and never travels with the library — your Spotify credentials and this device’s theme are left out of the database entirely.

Album lengths

Reads real running times from Spotify, so the target means something and each card can link straight to the album instead of a search. Create a free app, then paste its credentials here.

Today → Spotify playlist

Replaces a playlist with the albums you marked as added, in the day’s order, taking only as many tracks from each as the library says — so a reissue’s remixes and demos stay off it. It uses the same client ID, but needs your own authorisation, which a catalogue credential cannot give.

Bulk import

Add albums from a spreadsheet. Reads .xlsx and .csv. Either a sheet with Artist / Album / Genre / Runtime columns, or the original layout with one genre per column. Nothing is added until you confirm.
